# SIMBridge 使用说明

SIMBridge 是一款 macOS 本地短信面板，用于连接 Baiwang / DJI / Quectel 类 4G USB 模块，读取模块内短信、发送短信，并查看当前 LTE 信号与基站小区信息。

当前仓库暂时只发布 macOS Apple Silicon / arm64 版本。

软件是本地应用，不需要云端服务。打开后会在 App 内窗口显示操作面板，底层只绑定 `127.0.0.1` 本机地址，不暴露到局域网。

## 主要功能

- 查看模块状态：SIM 状态、运营商、网络制式、信号强度、短信中心、短信存储。
- 收发短信：支持读取模块内短信、发送中文短信、删除短信。
- 短信筛选：全部、收件、已发、未读。
- 开发者模式：开启后解锁信号/基站信息、原始 AT 数据和短信原始 PDU。
- 短信邮件转发：通过 SMTP、STARTTLS 或 SSL/TLS 将新收到的短信自动发送到指定邮箱。
- 信号/基站信息：在开发者模式下查看运营商、MCC/MNC、LTE 频段、Cell ID、eNodeB、Sector、PCI、EARFCN、TAC、RSRP、RSRQ、RSSI、SINR、SRXLEV。
- 开机自启动：可在软件内开启或关闭系统登录后自动启动。
- App 内渲染：不再依赖外部浏览器打开页面。

## 系统要求

- macOS（当前打包版本为 Apple Silicon / arm64）。
- 一只兼容的 Baiwang / DJI / Quectel 4G USB 模块。
- 一张已激活、可收发短信的 SIM 卡。

已验证设备特征包括：

- USB Vendor ID：`0x2ca3`
- USB Product ID：`0x4006`
- 设备名可能显示为 `BAIWANG`

不同批次或不同型号的模块可能需要额外适配。

## 安装方法

1. 打开 `SIMBridge.dmg`。
2. 将 `SIMBridge.app` 拖到 `应用程序` 文件夹。
3. 从 `应用程序` 中打开 `SIMBridge.app`。

首次运行时，macOS 可能提示“无法验证开发者”。这是因为当前版本未做 Apple 签名和公证。

处理方式：

1. 右键点击 `SIMBridge.app`。
2. 选择“打开”。
3. 在弹窗里再次选择“打开”。

也可以在“系统设置 > 隐私与安全性”中允许运行。

## 快速开始

1. 将 SIM 卡插入 4G 模块。
2. 将模块插入 Mac。
3. 打开 `SIMBridge.app`。
4. 等待几秒钟，顶部状态显示“在线”。
5. 在“短信”页查看短信，或在“发送”区域发送短信。

如果软件显示未找到模块，请确认模块已经插好，并且没有被其他软件占用。

## 发送短信

在右侧“发送”区域填写：

- 号码：可以是普通手机号，也可以是服务号或短号，例如 `10690000`、`95555`、`12345`。
- 内容：当前版本按单条 UCS2 中文短信处理，建议控制在 70 个中文字符以内。

填写完成后点击“发送短信”，软件会弹出确认框。只有点击“确认发送”后才会真正发送。

号码规则：

- 输入中国大陆 11 位手机号时，软件会自动按 `+86` 处理。
- 输入服务号、短号时，不强制要求 11 位。
- 空号码无法发送。

## 查看短信

短信页提供四个筛选：

- 全部：读取模块里所有可见短信。
- 收件：显示已读和未读收件短信。
- 已发：显示模块存储中可读到的已发短信记录。
- 未读：只显示未读短信。

注意：并不是所有模块都会保存已发短信。如果模块没有保存，已发列表会显示为空。

开启开发者模式后，每条短信下方可以展开“原始 PDU”，用于技术排障。普通用户无需查看。

## 信号/基站信息

先在右侧设置区开启“开发者模式”，再点击“信号/基站”查看实时网络信息。开发者模式关闭时，信号/基站入口和原始调试数据不可用，不影响短信收发、查看、筛选和删除。

常见字段含义：

- 运营商：当前注册的运营商名称，例如 `CHN-CT`。
- MCC/MNC：移动国家码和移动网络码，例如 `460 / 11`。
- 频段：当前 LTE Band，例如 `LTE BAND 1`。
- RSRP：LTE 参考信号接收功率，越接近 0 通常越好，例如 `-80 dBm`。
- RSRQ：LTE 参考信号接收质量，数值越接近 0 通常越好。
- SINR：信噪比，通常越高越好。
- RSSI：接收信号强度。
- Cell ID：当前服务小区编号，不是手机号、SIM 卡号或设备序列号。
- eNodeB / Sector：由 Cell ID 拆分出的 LTE 基站编号和扇区编号。
- PCI：物理小区标识。
- EARFCN：LTE 频点编号。
- TAC：跟踪区码。
- SRXLEV：小区选择接收电平值。

这些信息主要用于信号排查、网络定位和模块调试。普通收发短信场景可以不用关注。

## 开机自启动

软件右侧底部有“开机自启动”开关。

开启后，软件会在当前用户目录创建：

```text
~/Library/LaunchAgents/com.wangquanrun.simbridge.login.plist
```

关闭后会删除这个启动项。

注意：

- 不需要管理员权限。
- 请先把 App 拖到“应用程序”里，再开启自启动。
- 如果直接从 DMG 中运行，软件会提示先安装到“应用程序”，避免自启动路径指向临时挂载卷。

## 短信邮件转发

1. 在右侧设置区点击“短信邮件转发 > 配置”。
2. 填写 SMTP 服务器、端口、加密方式、用户名、密码或授权码、发件邮箱和收件邮箱。
3. 先点击“发送测试邮件”验证配置，再勾选“启用自动邮件转发”并保存。

首次启用时，软件会把模块中已有短信设为基线，只转发之后新收到的短信。软件关闭时不会主动检查短信；重新打开后会继续处理尚未转发的新短信，因此建议配合开机自启动使用。

SMTP 密码或授权码保存在当前用户的 macOS 钥匙串，不会写入转发配置文件。部分邮箱要求先在网页版开启 SMTP 服务，并使用单独生成的授权码，而不是网页登录密码。

## 常见问题

### 打开软件后提示找不到模块

请检查：

- 模块是否已插入 Mac。
- SIM 卡是否插好。
- 是否有其他软件正在占用模块。
- 模块硬件版本是否兼容。

可以尝试拔插模块后重新打开软件。

### SIM 状态不是 READY

可能原因：

- SIM 卡未插好。
- SIM 卡未激活。
- SIM 卡启用了 PIN 码。
- 模块尚未完成注册网络。

建议关闭 SIM PIN，并等待几秒后刷新。

### 可以收短信但不能发短信

请检查：

- SIM 套餐是否支持短信发送。
- 短信中心号码是否正常显示。
- 目标号码是否填写正确。
- 内容是否超过当前单条短信长度限制。

### 已发短信列表为空

这是正常情况。部分模块发送短信后不会把记录保存到模块存储中，所以“已发”页可能为空。

### 短信出现乱码

当前版本已处理 UCS2 中文短信、长短信 UDH 分片头和常见 PDU 编码。如果仍出现乱码，请保留该条短信的“原始 PDU”，用于后续适配。

### 信号页里的 Cell ID 是什么

Cell ID 是当前连接的 LTE 服务小区编号。它不是手机号，不是 SIM 卡号，也不是设备 ID。

它可以用来判断模块当前连接到哪个运营商小区，便于排查信号和网络覆盖问题。

## 隐私与安全

- 软件只在本机运行。
- 本地 HTTP 服务只绑定 `127.0.0.1`。
- 不会主动上传短信、号码、信号或基站信息到云端。
- 发短信前会弹出确认框，避免误触发送。

## 技术说明

软件通过 USB/libusb 与模块通信，使用 AT 指令完成短信和网络信息读取。

主要 AT 指令包括：

- `AT+CMGF=0`
- `AT+CMGL`
- `AT+CMGR`
- `AT+CMGS`
- `AT+CMGD`
- `AT+CPIN?`
- `AT+COPS?`
- `AT+CSQ`
- `AT+CPMS?`
- `AT+CSCA?`
- `AT+QENG="servingcell"`
- `AT+QNWINFO`
- `AT+QSPN`

主要本地接口包括：

- `GET /api/status`
- `GET /api/messages?box=all|inbox|sent|unread`
- `GET /api/message?index=...`
- `POST /api/send`
- `POST /api/delete`
- `GET /api/radio`
- `GET /api/autostart`
- `POST /api/autostart`
- `GET /api/forwarding`
- `POST /api/forwarding`
- `POST /api/forwarding/test`

打包后的 App 内置 Python 运行时、静态前端资源、`pyusb`、`pywebview` 以及对应平台的 `libusb` 动态库。

## 卸载方法

1. 退出 `SIMBridge.app`。
2. 删除“应用程序”里的 `SIMBridge.app`。
3. 如果开启过开机自启动，可以先在软件里关闭；也可以手动删除：

```text
~/Library/LaunchAgents/com.wangquanrun.simbridge.login.plist
```

删除后重新登录 macOS 或重启即可完全移除自启动项。
