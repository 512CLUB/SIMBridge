# 手机端与长期短信存档

Mac 版 SIMBridge 现在可以作为局域网短信服务器。只要 Mac、4G 模块和 SIMBridge 保持运行，同一 Wi-Fi 下的手机就能查看长期存档、发送短信、搜索内容、添加备注、收藏以及删除记录。

## 连接手机

1. 在 Mac 上打开 SIMBridge，并确认系统防火墙允许它接收入站连接。
2. 在右侧“手机连接”中点击“设置账号”，设置手机登录账号和至少 8 位密码。
3. 在同一区域查看手机访问地址和 6 位配对码。
4. 让手机和 Mac 连接同一个 Wi-Fi，在手机浏览器中打开该地址。
5. 先验证账号和密码，验证通过后再输入 Mac 上显示的配对码。
6. iPhone 可通过 Safari 的“分享 > 添加到主屏幕”创建快捷入口；Android 可通过浏览器菜单添加到主屏幕。

配对码会在 SIMBridge 每次重新启动后更新。账号密码验证产生的临时凭证有效期为 5 分钟，并绑定当前手机地址。已经配对的手机在服务运行期间会保持登录；服务重启或 Mac 端修改账号后，需要重新完成两步验证。

## 长期存档

- SIMBridge 运行时会定期读取模块中的短信，并保存到 Mac 的 SQLite 数据库。
- macOS 数据库默认位于 `~/Library/Application Support/SIMBridge/messages.db`。
- 从 SIM/模块删除短信不会删除 Mac 上的长期存档。
- “删除存档”是永久操作；为避免短信仍在模块中时再次出现，已删除记录会保留一个不含短信正文的删除标记。
- 成功从手机或 Mac 发送的短信也会进入“已发”存档，即使模块本身不保存已发短信。

## 使用范围与安全

- 当前手机端面向同一局域网使用，不会自动暴露到互联网。
- 除静态登录页面外，短信接口必须先通过账号密码验证，再通过 6 位码配对后才能访问；连续输错会被临时限制。
- 手机登录密码只以 PBKDF2-SHA256 加盐哈希保存在 `~/Library/Application Support/SIMBridge/mobile_access.json`，不保存明文。
- 当前局域网测试版使用 HTTP，账号和密码只应在可信 Wi-Fi 内使用。需要跨公网访问时，应先配置 HTTPS 或可信 VPN。
- Mac 必须保持开机，SIMBridge 必须保持运行，手机才可以收发和刷新短信。
- 直接从公网开放端口并不安全。如果后续需要外网访问，建议增加 HTTPS 和可信 VPN，不要直接做路由器端口映射。
